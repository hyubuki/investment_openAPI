# 로컬 Docker 실행 및 HTTP 테스트

## 사전 조건

- Docker Desktop 또는 Docker Engine과 Docker Compose v2
- JDK 17 이상

`.env.example`에는 로컬 전용 기본값만 포함한다. 값을 변경하려면 다음과 같이 복사하며 `.env`는 Git에 포함하지 않는다.

```bash
cp .env.example .env
```

## Docker 이미지 빌드

다음 작업은 전체 Gradle 테스트를 먼저 실행한 후 애플리케이션 이미지를 빌드한다. Redis 통합 테스트는 Testcontainers를 사용하므로 Docker가 실행 중이어야 한다.

```bash
./gradlew dockerBuild
```

## 로컬 환경 기동

PostgreSQL, Redis와 애플리케이션을 빌드하고 기동한다.

```bash
./gradlew localUp
```

기동 상태와 로그는 다음 명령으로 확인한다.

```bash
docker compose ps
docker compose logs -f app
```

## HTTP 테스트

IntelliJ HTTP Client에서 `http/local-user.http`를 열고 위에서 아래 순서로 요청을 실행한다.

1. 사용자 등록과 자동 로그인 Token Pair 검증
2. 로그인과 단일 활성 Session 교체 검증
3. Refresh Token Rotation과 재사용 탐지 검증
4. 로그아웃 멱등성 검증
5. 중복 이메일과 잘못된 입력 오류 계약 검증

## 종료

다음 작업은 컨테이너만 종료하며 PostgreSQL과 Redis 볼륨은 삭제하지 않는다.

```bash
./gradlew localDown
```

볼륨 삭제는 저장된 로컬 데이터를 모두 제거하므로 명시적으로 필요한 경우에만 `docker compose down --volumes`를 실행한다.
